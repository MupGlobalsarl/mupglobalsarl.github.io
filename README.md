# mupglobalsarl.github.io

Racine du site MUPGLOBAL SARL :

- `.well-known/assetlinks.json` relie l'application Android MUPGLOBAL PV (com.mupglobal.pv) au site ; la racine redirige vers /pv/.
- `/elec/` : **MupGlobal Électricité**, application installable de dimensionnement électrique de bâtiment (circuits, phases, branchement, réseau de terre, schémas, note de calcul et devis), utilisable hors connexion.
